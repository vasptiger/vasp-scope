## 一、七个页签

### 1. 收敛图表
- **离子步**：能量（相对末步 ΔE / 绝对 E）+ 最大力，双 Y 轴；科学计数法开关
- **电子步**：|ΔE| + SCF 残差 rms，双对数
- **离子步 # 切换**：静态单点任务自动只看电子步
- 数据来源：OSZICAR + OUTCAR（尾部解析）

### 2. 能带
- 读 `BAND.dat`（多块；块间 k 重新起算 → 用**累积路径坐标**拼接）
- **自旋↑/↓ 分栏**（仅当数据真有分裂时）
- **X 轴高对称点**：优先级 `KLABELS`（`G 0.000` 自带标签+坐标）→ `KPOINTS + 倒格矢`算距离 → 段界比例；**只写字母、不退回数字**
- Y 轴**固定 ±6**（脚本 `YLIM=(-6,6)` 口径）；曲线**裁剪到坐标框**（深带到 −51 eV 也不溢出）
- 可叠 PDOS（`PDOS` 开关）
- 自旋简并检测：上下旋数值一致时提示

### 3. PDOS
- 读 `PDOS_*` / `IPDOS_*`（`PDOS_` 优先）；分元素 Li/O/Mn，可逐个开关 + `[全开]`
- **自旋镜像**：右半 ↑、左半 ↓，**直接画文件里的带符号值**（不取绝对值、不人为取负）
- **总态密度** `TDOS.dat`：深灰粗线，纳入图例与尺度
- 三通道 s / p / d（`p` = 2..4 列之和、`d` = 5..9 列之和，不含 tot）
- 横向：**每通道各自归一化 × 0.35**（形状优先；与脚本"d/p 定尺度 ×1.08"口径**不一致**，待定）
- 纵向：**下界 −10**、上界贴数据 +5% 余量（由 PDOS 自己的数据算，不看能带）
- 强度轴刻度（镜像时左右对称）

### 4. 能垒
- 读 NEB/过渡态 `*.dat`（多文件叠加，排除 `fe.dat`）
- **X 口径 5 种**：自动 / 累积距离归一化 / 每步差值 / 累积距离(Å) / 图像编号；可反转
- **完成门槛**：末行相对能量 ≈ 0 才判为"跑完"
- **三级取数**：`/plot` → `/read` 逐文件 → 从 image 目录（00/01…）算距离
- 峰高标注（相对初态）

### 5. 3D 结构
- 读 `CONTCAR`（缺则 `POSCAR`）
- 显示模式：球 / 空间填充 / 多面体（可按中心元素筛）
- 配色：**VESTA 原色**
- 视角：晶轴正视图（`a` / `b` / `c` 按钮）、绕轴 90°X/Y/Z、复位、缩放
- 键长判据：VESTA 字典 / 第一配位壳 / 固定阈值 + 全局缩放；边界模式
- 视角记忆（只读不算交互）、元素图例

### 6. 文件
- 任务目录文件列表（名称/大小/时间/分类）
- **文本阅读器**：分块读取 + 「继续读」
- **图片预览**：`png/jpg/jpeg/gif/webp/bmp/svg`；走宿主 `/img`（base64 原样回传）→ 面板用 **canvas + createImageBitmap** 解码（绕过 `img-src` 限制）；超 6 MB 拒绝、超 4096 px 自动缩

### 7. AIMD
- **MSD**：`MSD.dat`（时间 fs→ps、x/y/z/tot）；拟合窗口按 **ps**、可勾「过原点」；同时给**全段**与**后段 50–100%** 两个 D；叠 VASPKIT `DIFFUSION_COEFFICIENT.dat` 末值对照
- **RDF**：目录内全部 `RDF_<A>-<B>.dat`，每对一条线 + 图例；认 `COORDINATION_NUMBER_*`（暂未叠轴）
- 页内有 **MSD / RDF 切换按钮**

## 二、全局与顶栏

| 功能 | 说明 |
|---|---|
| 任务树 | **嵌套目录**、默认收起、蓝色目录图标、展开状态记忆 |
| 表格视图 | 列排序、状态色 |
| 搜索 | 按元素 / 计算类型 / 关键字 |
| 扫描 | 深度 8 层、一次 ssh 批量（`/scan` 900 s 超时）、56+ 任务 |
| 状态判定 | 5 态（完成 / 正常收尾 / 失败 / 未完成 …）+ 证据行 |
| 计算类型判定 | **只留结论**（`判定：…`），已删除"依据 ← / 规则 / KPOINTS"等实现说明 |
| 任务事实 | rel_path · 元素顺序 · 计数 · 离子步 · OUTCAR/vasprun 大小 · 收敛证据 · 源目录 |
| 刷新 | 手动（不做轮询） |
| **导出** | 逐项 PNG：收敛 / 能带 / PDOS / 能垒 / MSD / RDF / 3D（2× 白底）+ 整块面板 PNG；逐项 CSV：收敛 / 能带 / PDOS / 能垒 / MSD / RDF；全部任务 + 数据 JSON |
| 主题 | **仅深色**（浅色主题已按需求移除） |
| 深链 | `?tab=`（页签）· `?task=`（任务）· `?token=` · `?scfstep=` · `?rscale=` · `?zoom=` |
| 连接态 | 未连接/离线提示；切任务自动刷新当前绘图页签；缓存自愈（有文件但缓存空 → 重取） |

## 三、宿主侧（插件，10 条路由）

| 路由 | 用途 | 超时/限制 |
|---|---|---|
| `/plot` | **一次 ssh 取全部谱图**（能带 / PDOS / KLABELS / 能垒） | 抽稀：band >200 KB、PDOS 3 点 |
| `/scan` | 任务表（状态/元素/计数/INCAR 子集/KPOINTS 类型/停用标记） | **900 s** |
| `/task` | 单任务文件清单 + 判定依据 | 300 s |
| `/read` | 分块读远端文件（base64 二进制安全） | 180 s；**先截到 `__END__`** |
| `/img` | 图片整文件 base64（宿主不解码） | 6 MB 上限；白名单扩展名 |
| `/convergence` | 收敛序列（离子步 + 电子步） | — |
| `/list` · `/panel` · `/ping` | 目录列表 / 面板 HTML / 连通性 | — |
| `/diag` | **自诊断**（已注册路由、注册失败的） | 第一位注册，保证可用 |

其它：ssh 通道（Win32-OpenSSH，别名 `mycluster`）· 目录白名单（`/home/user/projects/demo`、`/home/shared/projects`）· token 鉴权（可空 = 不鉴权）· CORS `*`（`file://` 面板取数需要）
